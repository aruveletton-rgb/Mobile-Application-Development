# 备案与上架材料包

日期：2026-10-25　对应：`docs/课程要求优先裁定_20261025.md` 裁定后的关键路径
性质：**材料清单与填写指引**，不是已完成材料。带【】的是必须由主体持有人填的真实信息，代理不能代填、不能编造。

---

## 1. 两件不同的事，别混

| | APP 备案 | 应用市场审核 |
|---|---|---|
| 主管 | 工信部 / 属地通信管理局 | 华为 AGC |
| 依据 | 《移动互联网应用程序备案》 | 华为应用审核指南 + 资质要求 80301 |
| 谁提交 | APP 主办者（通过接入商，如华为云） | 开发者账号持有人 |
| 耗时 | 管局 7—20 工作日，首次主体整体 3—5 周 | 1—3 工作日/轮 |
| 不做的后果 | 不得从事互联网信息服务 | 不得上架 |

**顺序**：主体实名 → 域名实名 → 服务器包周期 → 备案 → 上架审核。备案号是上架的前置，不是并列项。

## 2. APP 备案材料清单

| # | 材料 | 说明 | 谁提供 |
|---|---|---|---|
| 1 | 主体证件 | 个人：身份证正反面；企业：营业执照 | 用户 |
| 2 | 主体负责人证件 + 手机号 | 需接收核验短信 | 用户 |
| 3 | 域名 | 已完成实名，且实名信息与主体一致 | 用户 |
| 4 | 服务器 | 华为云大陆节点，包周期且剩余时长满足属地要求（通常 ≥3 个月） | 用户 |
| 5 | 备案授权码 | 由 Flexus L / ECS 实例生成 | 用户（控制台点一下） |
| 6 | APP 名称 | 与 AGC 创建时完全一致 | 待定 |
| 7 | **软件包名** | 与 `app.json5` 的 `bundleName` 完全一致 | 待定（现为 `com.example.*`，必须换） |
| 8 | 公钥 / 签名信息 | 备案要求提交 APP 签名公钥 | 需先生成签名 |
| 9 | APP 服务内容描述 | 如实写"校园信息查询与办事指引" | 代理起草，用户确认 |
| 10 | 隐私政策链接 | 必须是可公开访问的 HTTPS 页面 | 本次已出草案 |
| 11 | 承诺书 | 个人主体需《个人开发者承诺函》（上架用）；备案另有告知承诺书 | 用户签署 |

**关键顺序坑**：备案要包名和公钥，公钥来自签名，签名要在 AGC 建应用之后。所以真实顺序是
**AGC 建应用 → 生成签名 → 取公钥 → 备案 → 提审**。备案和签名不是可以并行省掉的一步。

## 4. 隐私标签：本项目实际收集什么

| 数据 | 是否收集 | 用途 | 存储位置 |
|---|---|---|---|
| 课程/考试日程 | 是（用户主动导入 CSV/ICS） | 本地展示与提醒 | **仅本机** |
| 偏好设置 | 是 | 界面与默认项 | 仅本机 |
| 对话历史 | 是 | 上下文与历史查看 | 仅本机 + 服务端会话（可删） |
| 报修填写内容（地点、描述、联系方式） | 是 | 生成工单草稿并提交 | 服务端 |
| 账号/身份 | 视方案 | 区分数据域与权限 | 服务端 |
| 位置、通讯录、相册、剪贴板 | **否** | — | — |
| 设备标识符 | 否 | — | — |

**这条必须与代码一致**。上架前用真机抓一次网络请求，逐条核对；隐私标签写"不收集"而实际发了，是典型驳回原因。

## 5. 高频驳回点（本项目逐条对照）

| 驳回原因 | 本项目现状 | 处理 |
|---|---|---|
| 正式包含测试数据 | 全合成数据 | 上架前切 live 模式，无真实数据时显示空态 |
| 功能异常/白屏 | 后端仅回环 | 必须公网部署 |
| 应用名称泛词/相似 | "校园智能助手" | 改名 |
| 图标与截图不一致 | 仅 SVG | 出 PNG 并三处比对 |
| 未提供隐私政策 | 无 | 已出草案 |
| 无首启同意 | 无 | 客户端改造（工单 C-1） |
| 权限无使用场景说明 | 仅代码声明 | AGC 隐私说明逐项写 |
| 未备案 | 无 | 备案 |
| 声称 AI 但无资质 | UI 有"AI 助手"字样 | 改文案或办资质 |

## 6. 与课程、大赛的关系

| 事项 | 移动课程 | 仓颉课程 | ICT 大赛 |
|---|---|---|---|
| 备案 | 上架硬前置 | 无关 | 云端 Demo 的合规基础 |
| 软著 | 非必选（华为） | **+10 分**（需教师为著作权人之一） | 入围开源要求另算 |
| 隐私政策 | 上架必需 | 无关 | 数据处理说明可复用 |
| 备案号 | 上架必需 | 无关 | 云上服务合规证据 |

> 软著是唯一"一份材料服务两门课"的项：仓颉给加分、华为非必选但能降低人工审核不确定性。前提是教师同意署名。
